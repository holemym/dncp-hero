הקובץ לדפוס

שש בדיקות לפני ששולחים. כל אחת לוקחת דקה.

  1. גלישה רקע וצבעים עד 3 מ״מ° מעבר לקו החיתוך.
  2. שוליים טקסט ולוגו לפחות 3 מ״מ° בתוך הקו.
  3. CMYK שומרים את הקובץ ב־CMYK.
  4. רזולוציה תמונות ב־300 DPI° בגודל ההדפסה, או לוגו וקטורי.
  5. גופנים ממירים טקסט לקווים או מטמיעים את הגופנים ב־PDF.
  6. שחור טקסט קטן בשחור 100% בלבד; משטחים גדולים בשחור עשיר°.
